# Signex Web + Workshop

Traductor ASL/LESCO con MediaPipe y modelos exportados para el navegador.
Incluye el modelo de **24 letras LESCO** entrenado por Adrián Durán (incluida T),
así como los modelos web ASL existentes. Las palabras LESCO aún necesitan
entrenamiento y exportación independientes.

Para probarlo localmente: `python launcher.py` y abre la dirección que imprime.
Consulta [INSTALACION.md](INSTALACION.md) para despliegue y Workshop.

Autores originales: Dilan Calvo, Adrián Durán y Nazareth Solís.
